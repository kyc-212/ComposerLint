# ComposerLint Skills

Keep all three authoritative folders together: `composer-import`, `composer-review`
and `composer-edit`. Their SKILL.md files cross-reference one another. Project-local
relative links under `.agents/skills/` expose the authoritative copies without a
global installation. Verify discovery in a fresh client session after reconnecting
the local MCP server.

Use the interpreter and arguments in [installation](../../docs/INSTALL.md). Codex is
the demonstrated client; other clients need compatible MCP, local file access and
their supported Skill-loading mechanism. Interactive behavior is not automatically
verified in another client or platform.

- `composer-import` technically prepares MXL and conditional MSCZ inputs. Conversion
  alone stops after reporting the verified working path.
- `composer-review` supplies source-grounded review, evidence retrieval, viewing and
  selected-passage follow-ups.
- `composer-edit` coordinates exact previews and supported expressive/rhythm/creation
  workflows, retaining independent verification and personally operated export.

Try “Review my piece” or “Open this score” with an absolute server-visible path.
Review/edit automatically route compressed inputs through the importer. MIDI remains
analysis-only; PDF/audio/URLs are unsupported. Fresh live selection is preferred for
“Analyze these measures”; genuine instrument/voice ambiguity still needs clarification.
Import success and creative discussion never constitute export approval.

See [README](../../README.md) and [installation](../../docs/INSTALL.md) for operation
bounds, patched renderer setup, MuseScore behavior and source-only distribution
limits. Keep the authoritative SKILL.md safeguards; do not bypass a typed refusal
through shell rewriting or automatic software installation.
