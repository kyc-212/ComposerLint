# ComposerLint Windows x64 Full setup

Use the [Windows installation instructions](docs/INSTALL.md#windows-x64-full-setup)
for the two ZIPs, independent verification, installation and connecting the viewer.
This is an unsigned Windows x64 test package. Full setup creates its own private
installation and prints a separate MCP command and renderer configuration. Keep
your existing Run #26 text-only installation and its MCP entry.

The setup ZIP includes the reviewed five-file manifest at
[tools/windows-full-artifacts.json](tools/windows-full-artifacts.json). Obtain the
ZIP hashes and manifest digest through the trusted handoff. The accompanying
[Windows renderer audit](docs/licensing/windows-renderer-audit.md) identifies the
evidence required before binary distribution.
