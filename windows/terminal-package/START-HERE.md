# ComposerLint Windows x64 Full setup

Follow the [Windows installation instructions](docs/INSTALL.md#windows-x64-full-setup)
to verify the unsigned test package and run `Setup.ps1` in Windows PowerShell.
Full setup can use the verified standalone renderer ZIP, reuse a private
renderer from a completed installation, or build one with LLVM-MinGW.
Setup prints the MCP command and renderer configuration for a separate
client entry. Keep your existing installation and MCP entry available.
